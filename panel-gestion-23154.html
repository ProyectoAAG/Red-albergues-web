Administrador de instalaciones

Zona privada para añadir, editar y borrar instalaciones de Firestore. Debe iniciarse sesión para poder usar el panel.

Acceso

Inicia sesión con correo y contraseña configurados en Firebase Authentication (Email/Password).

Gestión de instalaciones

Acciones
Modo · Nueva instalación

Rellena los datos de una nueva instalación. Cualquier campo que no se conozca se guardará como “Sin información”.

Modo · Editar instalación
Selecciona instalación a editar
Al seleccionar, se cargarán los datos en el formulario de abajo. Luego pulsa “Guardar cambios”.
Modo · Borrar instalación

Selecciona una instalación para eliminarla de la base de datos. Esta acción no se puede deshacer.
